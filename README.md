# Tech News

Estudo de layout para um portal de notícias sobre tecnologia.

![Status](https://img.shields.io/badge/status-Prot%C3%B3tipo%20%E2%80%94%20n%C3%A3o%20finalizado-blue?style=flat-square)

**Tecnologias:** HTML · CSS · JavaScript · Phosphor Icons

## Sobre

Interface de portal com destaques, categorias e notícias organizadas em cards. O foco atual é a composição visual; os textos são demonstrativos e não há publicação editorial ou backend.

## O que já existe

- Layout de notícias e áreas de destaque.
- Menu móvel e animações de entrada.
- Imagens locais e ícones externos.

## Como visualizar

Clone o repositório e abra `index.html` no navegador. Para testar por HTTP, use a extensão Live Server do seu editor. Preserve as pastas de CSS, JavaScript e imagens. Não há dependências locais para instalar; recursos de CDN exigem internet.

## Observações

Os links com destino # e o botão de busca ainda são elementos de demonstração. A imagem substituta de impressão 3D é uma ilustração, não uma fotografia da notícia.
